# Lab1
## Цель работы
Реализовать веб-приложение на Spring Boot, которое обрабатывает данные формы, использует шаблонизатор Thymeleaf и реализует передачу данных между контроллером и представлением через Model.

## Архитектура проекта
- **Стек:** Spring Boot 3, Maven, Thymeleaf.
- **Основные слои:** 
  - Controller (MainController) - обрабатывает HTTP-запросы (GET/POST), принимает данные от клиента, взаимодействует с моделью и возвращает представление.
  - Model (Student) - POJO-класс, представляющий сущность Студент. Содержит поля, геттеры, сеттеры. Используется для передачи и хранения данных формы.
  - View (Thymeleaf шаблоны) - HTML-страницы (main.html, about.html, main-form.html, result.html) с использованием синтаксиса Thymeleaf для динамического отображения данных и работы с формами.
- **Ключевые аннотации:**
- @SpringBootApplication - запуск Spring Boot приложения.
- @Controller - определение класса как веб-контроллера.
- @GetMapping и @PostMapping - маппинг HTTP-запросов на методы контроллера.
- @RequestParam - извлечение параметров из строки запроса.
- @ModelAttribute - привязка данных формы к объекту модели.

## Алгоритм работы
При запуске приложения активируется сервер на порту 8080. При обращении к главной странице / контроллер возвращает main.html. При обращении к /about контроллер извлекает параметр через @RequestParam и отображает его на странице about.html. При GET-запросе к /form контроллер создает пустой объект Student и передает его в форму main-form.html. Пользователь заполняет поля и отправляет форму методом POST на адрес /form. Контроллер получает заполненный объект Student через @ModelAttribute, из года поступления извлекает последние две цифры, формирует группу по шаблону ПИНз-1 + две цифры года и логин по шаблону student- + группа + - + id. Сгенерированные данные сохраняются в объекте Student, который передается на страницу result.html для отображения.
